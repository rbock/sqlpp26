## 0.71
- Removed the CMake module targets (`sqlpp26::*_module`) because they did not work reliably with recent compilers. Instead you can manually add the sqlpp26 module interface files to your projects. For details see the [modules documentation](/docs/modules.md).

First release of sqlpp26

It is tagged 0.71 as it is a continuation from sqlpp26-0.70.

Major differences for library users are documented in
